# Hoài Trinh Localize Library

Kho dữ liệu online chính thức cho **Hoài Trinh Localize Studio**.

Repository này lưu danh mục game, metadata và thông tin phiên bản Việt hóa để Launcher có thể cập nhật thư viện mà người dùng không cần tải lại Tool.

## Trạng thái hiện tại

- Combolands
- Wanderburg

Giai đoạn hiện tại: **miễn phí**, chưa yêu cầu tài khoản hoặc đăng nhập.

> File trung tâm mà Launcher đọc: `library.json`
